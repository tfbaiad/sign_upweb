高校联赛统一管理后台升级说明

本次改造以现有项目为基础：
1. 管理员统一入口为 /admin.html。
2. 原报名/承诺书管理、缴费审核、比赛发布、公告管理、管理员账号管理整合为同一页面内的标签页。
3. 选手门户左侧导航移除“管理后台”入口。管理员直接访问 /admin.html。
4. /admin-operations.html 自动跳转至 /admin.html，避免旧书签失效。
5. 公告发布后会显示在选手端 /news.html。

部署：将本目录内容合并到原 GitHub 仓库，不要删除原文件或 D1 数据。
数据库：在原有 LEAGUE_DB（zjggxcsls）上仅执行 migrations/0008_announcements.sql 一次。不要重复执行 0006/0007。
Cloudflare Pages 构建设置沿用原项目；静态目录仍为 public（如果原项目已有设置，不要随意改动）。

管理员入口：https://你的域名/admin.html
注意：部署后需用管理员账号登录，逐项测试报名、承诺书、缴费审核、比赛发布、公告发布与选手端公告显示。
