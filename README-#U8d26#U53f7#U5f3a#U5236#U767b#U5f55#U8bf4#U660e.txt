高校联赛门户：强制注册/登录说明

本次修改：
1. 所有选手端门户页面（首页、报名、承诺书、个人信息、缴费、战队、比赛、积分榜、公告、规则）打开时，先请求 /api/auth/me 检查登录状态。
2. 未登录时显示统一的登录/注册界面，不显示门户内容；注册需要用户名、至少10位密码和 Steam64 位 ID。
3. 注册/登录成功后自动进入当前页面；登录状态使用服务端 HttpOnly Cookie，不使用 localStorage 保存密码或会话令牌。
4. 顶部显示当前登录用户名，并提供退出登录。
5. 退出后回到首页，必须重新登录才能继续访问选手端页面。

部署：
- 将本包 sign_upweb-main 文件夹内容合并进现有 GitHub 仓库。
- 不要删除原文件、D1 数据库或历史数据。
- 确认 functions/api/auth/register.js、login.js、me.js、logout.js 和账号相关迁移已部署。
- 如果此前已经执行过 0006/0007，不要重复执行。
- 提交 GitHub 后等待 Cloudflare Pages 部署。

测试：
1. 用无痕窗口打开首页，应先出现登录/注册界面。
2. 注册一个新账号，必须填写 Steam64。
3. 注册成功应进入首页；顶部显示用户名。
4. 点击左侧“我的报名”等菜单，应进入对应页面，不再要求重复登录。
5. 点击顶部退出，再打开任意选手端分页，应再次出现登录界面。

说明：本次在现有门户脚本中增加统一前端登录门禁，并复用项目已有的 /api/auth/* 后端接口。它能阻止未登录用户通过页面导航进入选手端页面；真正的数据安全仍以各个 API 服务端的登录校验为准。管理员页面建议继续使用原管理员登录，不要把选手账号当作管理员权限。
